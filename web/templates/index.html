What happens when you press the button

  1. The request is validated twice: here, and again inside the root-only provisioning script.
  2. A static address and MAC are allocated from a small pool on the hypervisor's bridge.
  3. A CNAME for the new hostname is created through the Cloudflare API.
  4. A Butane config carrying your message is transpiled to Ignition.
  5. A copy-on-write qcow2 overlay is laid on the shared Flatcar image and a transient libvirt domain is started; Ignition arrives over QEMU's fw_cfg.
  6. The guest boots, applies its static network config, and starts nginx (in Docker) serving the page.
  7. Once the guest answers HTTP, a server block is added to the hypervisor's nginx, tested, and reloaded.

Every step is logged to the job page, and any failure rolls back what was already done.
